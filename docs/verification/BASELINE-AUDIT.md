# Baseline audit

Locations refer to the initial workspace snapshot. The review covered the application, limiter, configuration, tests, packaging, workflow, setup guides and MIT license. Security observations describe the affected behavior and the local assertions used to validate the correction.

| Severity | Original location                                                                  | Verified behavior and impact                                                                                                                                                                                         | Correction and regression check                                                                                                                                      |
| -------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| High     | `src/middleware/rate-limit.ts:5`                                                   | Lowercasing preserves distinct spellings of the same IPv6 address. Only the exact dotted, lowercase IPv4-mapped spelling is folded. Equivalent identities can occupy separate quota buckets.                         | Parse validated addresses and canonicalize them, including mapped IPv4. Assert that equivalent spellings share exactly one bucket.                                   |
| High     | `src/app.ts:16`, `src/config.ts:33`                                                | A positive hop count treats the socket peer as a proxy regardless of its identity. If a direct path exists, forwarding headers can affect the selected IP. Default zero is safe for direct traffic.                  | Replace hop-only trust with a validated source IP/CIDR allowlist. Test a trusted loopback peer, an unlisted direct peer and invalid selected values.                 |
| High     | `src/config.ts:30–32`, `src/limiter/sliding-window.ts:45–56`                       | The two per-dimension maxima permit a theoretical ten billion timestamps. Both variables accept their maxima together, so a plausible-looking config can outgrow process memory under load.                          | Enforce a joint timestamp budget at startup and in the limiter constructor. Test the product boundary and rejection.                                                 |
| Medium   | `src/limiter/sliding-window.ts:58–65,119–133`                                      | Injecting times 100, 0, 1000 with a 1000 ms window and quota 2 leaves an expired timestamp behind an active one. Non-finite samples also reach the store, and the reset clamp hides invalid ordering.                | Use a monotonic default, clamp regressed valid samples to the high-water mark and reject invalid samples. Test ordering, reset, fractional time and expiry.          |
| Medium   | `src/limiter/sliding-window.ts:67–77,100–111`                                      | Every untracked request at capacity scans the full store, even if every bucket still has active entries. This converts churn into synchronous work proportional to tracked clients and can delay unrelated requests. | Maintain bucket order by latest acceptance and examine only the oldest bucket on admission. Assert reclamation order, no active eviction and recovery at expiration. |
| Medium   | `src/server.ts:19–31`                                                              | A connection in flight can keep `server.close()` pending. There is no shutdown deadline and a repeated signal can fall through to default termination.                                                               | Stop the sweep, drain the listener with a fixed deadline and share a single shutdown result. Test completing and stalled requests and idempotency.                   |
| Medium   | `src/app.ts:26,40–51`                                                              | Unsupported JSON charset or encoding falls through to HTTP 500. The generic error logger can log raw error objects containing request data. Compressed request bodies are inflated by default.                       | Disable inflation, classify known parser errors, use generic error messages and log no request payloads. Exercise 400, 413, 415 and redacted 500.                    |
| Low      | `src/config.ts:16–17`                                                              | Empty numeric settings silently select a fallback. The regular expression's end anchor also matches before a trailing newline.                                                                                       | Validate explicit values as strict decimal strings. Test blanks, whitespace, sign, fractional and non-finite input.                                                  |
| Low      | `src/middleware/rate-limit.ts:19–27`, `src/app.ts:19–21,36–37`                     | Cache control is applied after identity validation and only on API requests that reach the limiter. Invalid IP, health and non-API 404 responses can lack the service's cache policy.                                | Apply no-store at the app boundary. Assert cache control on every response class.                                                                                    |
| Medium   | `package.json:16`, `scripts/smoke.mjs:1–29`                                        | The core command imports missing build output on a fresh checkout. Smoke relies on a separate server and can exit successfully with unexpected response codes.                                                       | Build as a prerequisite and run smoke against an isolated compiled listener with assertions and cleanup. Verify both from clean sources.                             |
| Medium   | `Dockerfile:1–10`, `.github/workflows/ci.yml:8–20`, `package.json:6–8`             | The snapshot has no lockfile, Docker uses a floating base tag and CI installs unlocked dependencies. Node 20 is end-of-life. CI omits lint, formatting and coverage.                                                 | Commit a lockfile, use `npm ci`, pin the base and exercise maintained runtime lines and all quality gates. Verify a clean checkout and container lifecycle.          |
| Low      | `README.md:27–49,89–135,160–169`, `SETUP-FA.md:9–48`, `docs/ARCHITECTURE.md:21–37` | Install, proxy, cache and memory descriptions mirror the baseline behavior and do not fully explain the deployment and retry contract.                                                                               | Update the examples and methodology to match the corrected implementation and measured releases.                                                                     |

An IP quota still groups clients that share an egress address and splits distinct IPv6 addresses. A multi-process quota and a hard heap bound are outside the in-process design. These are deployment trade-offs rather than additional baseline defects. The MIT notice is retained.
